Whirlpool Appliance Error Codes - Diagnosis and Repair Guide

Field-tested error code reference from our Northern Virginia repair technicians.

Whirlpool Error Codes: Quick Reference

Whirlpool appliances use F-codes and E-codes that flash on the control panel. The most common are F2E1 (stuck button), F5E2 (door lock), F8E1 (water supply), and F9E1 (drain issue). Many Whirlpool errors can be cleared by unplugging the appliance for 1 minute, but recurring codes need professional diagnosis.

Error CodeApplianceMeaningDIY?
F2E1Washer/RangeStuck button on control panelUnplug 1 min
F5E2WasherDoor lock mechanism failureCall tech
F8E1WasherLow water flow / supply issueCheck water valves
F9E1WasherLong drain timeClean drain filter
F1E1AllControl board communication errorCall tech

Whirlpool appliances use F-codes (fault codes) combined with E-codes (error codes) to pinpoint problems. Understanding these codes saves you time and helps you communicate clearly with your repair technician. This guide covers the codes we diagnose most often in Woodbridge, Dale City, and Northern Virginia homes.

Whirlpool Washer Error Codes

Whirlpool washers (including Cabrio, Duet, and newer top-load models) display F/E combination codes. The F-code identifies the system, the E-code identifies the specific fault.

Code Meaning What It Means & Repair Cost
F0 E1 Stuck Key Error A button on the control panel is stuck. Press each button to release. If persistent, control board or panel replacement: $100–$200.
F0 E2 Too Much Suds Excessive detergent detected. The washer adds extra rinses to clear suds. Use HE (High Efficiency) detergent only. Reduce the amount used.
F0 E5 Load Detected with Lid Open Washer senses a load but the lid is open. Close the lid firmly. Check the lid lock mechanism if the code persists.
F1 E1 Motor Control Error The motor control board has lost communication. Power cycle for 60 seconds. If it returns, the MCU board likely needs replacing: $150–$280.
F1 E2 Main Board Error The main electronic control board has a fault. Reset by unplugging for 1 minute. Board replacement: $180–$320.
F3 E1 Water Level Sensor Error The pressure transducer cannot detect water level. Check the pressure hose for clogs or cracks. Sensor: $60–$100.
F5 E1 Lid Switch Error The lid switch assembly does not detect the lid as closed. Could be a faulty switch or broken actuator tab on the lid. Lid switch assembly: $60–$120.
F5 E2 Door Lock Error The door lock mechanism on front-load models is not engaging. Door lock: $80–$150.
F7 E1 Motor Speed Error The motor is not reaching the expected RPM. Possible causes: worn carbon brushes, faulty rotor position sensor, or shift actuator problem. Repair: $100–$250.
F8 E1 Water Supply Error Low water flow or no water detected. Verify both supply valves are open. Clean inlet filter screens. Water inlet valve: $90–$160.
F8 E2 Dispenser Error The detergent dispenser is not functioning properly. Motor or actuator in the dispenser has failed. Cost: $80–$140.
F9 E1 Drain Error The washer did not drain within 8 minutes. Clean the drain pump filter (access panel at bottom-front). Check drain hose. Pump: $120–$200.

Whirlpool Dryer Error Codes

Whirlpool dryers use the same F/E code system. Many Whirlpool dryer codes relate to airflow and heating.

Code Meaning What It Means & Repair Cost
F1 E1 Main Board Error The electronic control board has a fault. Power cycle first. Board replacement: $150–$280.
F2 E4 Vent Restriction Exhaust airflow is restricted. Your dryer vent needs cleaning. Schedule professional vent cleaning to prevent fire risk.
F3 E1 Exhaust Thermistor Open The exhaust temperature sensor has an open circuit. Thermistor: $50–$90.
F3 E2 Moisture Sensor Error The drum moisture sensor bars are not reading properly. Clean sensor bars with rubbing alcohol. If still failing, sensor replacement: $60–$100.
F4 E1 Heating Error No heat detected. Electric: check heating element and thermal fuse. Gas: check igniter and gas valve solenoids. Element: $100–$180. Igniter: $80–$140.
F6 E2 Communication Error The user interface and main control board cannot communicate. Check wire harness connections. Board replacement if wiring is intact.

Whirlpool Dishwasher Error Codes

Whirlpool dishwashers (including Gold and QuietPartner series) display F-codes on the control panel or through blinking light sequences.

Code Meaning What It Means & Repair Cost
F1 E1 Temperature Sensor Error The water temperature sensor (NTC) has failed. The dishwasher may not heat water. Sensor: $50–$90.
F2 E2 User Interface Error The control panel has a communication fault. Reset by turning off the breaker for 60 seconds.
F3 E2 Heating Timeout The dishwasher cannot heat water to the target temperature within the allotted time. Check water heater supply temperature and heating element.
F5 E2 Door Switch Error The door latch switch does not detect the door as closed. Latch assembly: $50–$100.
F6 E4 Water Inlet Error Low water flow detected. Clean the inlet filter screen. Check supply valve. Inlet valve: $70–$130.
F8 E1 Slow Drain Water is not draining fast enough. Check drain hose, air gap, and garbage disposal connection. Drain pump: $100–$160.
F8 E4 Overflow Water overflow detected. Float switch or inlet valve problem.
F9 E1 Diverter Error The wash motor diverter disc has failed. The dishwasher cannot switch between upper and lower spray arms effectively.

Whirlpool Oven and Range Error Codes

Whirlpool ovens and ranges display F-codes on the oven display. Many relate to temperature sensing and door lock functions.

Code Meaning What It Means & Repair Cost
F1 E0 EEPROM Error The control board's memory has corrupted. Usually requires control board replacement: $150–$300.
F2 E0 Oven Temperature Too High The oven exceeded maximum temperature. The oven thermostat or relay has failed. Safety issue - do not use until repaired.
F3 E0 Open Oven Sensor The oven temperature sensor (RTD probe) has an open circuit. Sensor: $50–$100. Easy DIY repair if you're comfortable.
F3 E2 Shorted Oven Sensor The sensor has a short circuit. Same sensor replacement as F3 E0.
F5 E1 Self-Clean Door Lock Error The door lock mechanism failed during self-clean. The lock motor or switch has failed. Lock assembly: $80–$160.
F9 E0 Door Lock Error The oven door lock did not engage or disengage properly. Often occurs after self-clean cycles.
